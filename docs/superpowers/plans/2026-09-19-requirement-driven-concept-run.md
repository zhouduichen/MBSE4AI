# 需求驱动概念布局运行实施计划

## 目标

移除总体设计页面的硬编码示例输入，让需求分析结果成为 2.1/2.2 的真实上游。

## 步骤

1. 为概念布局 API 增加从当前 ModelGraph 自动构造 envelope 的运行分支。
2. 为 `ready` 和 `needs_input` 分别补 API/UI 验收；缺参不产生候选、不调用评估器。
3. 增加文档输入到 R→F→L→P→V&V 再到概念候选的离线端到端验收。
4. 清除页面固定翼示例参数，保留人工编辑后的显式 envelope 入口。
5. 运行全量离线门禁，更新能力文档，提交并推送。

## 非目标

本切片不接入新模型、不改变 LLM Provider、不启动本地或远程服务器、不替代工程师对 envelope 和候选方案的审查，也不声称开发评估为正式仿真证据。
