# MBSE4AI v0.2 Methodology Reconstruction Implementation Plan

> **For agentic workers:** Execute this plan task-by-task with a test checkpoint after each PR-sized phase.

**Goal:** Implement the user-supplied MBSE4AI v0.2 execution specification across Prompt, Validation, Gate, Repair, Workflow DSL, Context/Retrieval, and Benchmark layers.

**Architecture:** Extend the existing typed ModelGraph/Patch/CAS pipeline. Add focused methodology modules for prompt loading, validators, trace coverage, repair planning, completion routing, and context planning; keep WorkflowRunner as an orchestration facade and RuleRuntime as the offline regression baseline.

**Tech Stack:** Python 3.11+, dataclasses/StrEnum, package resources, jsonschema, SQLite repository, pytest, compileall, Import Linter.

## Global Constraints

- Follow PR-01 → PR-02 → PR-03 → PR-04 → PR-05 → PR-06 → PR-07 order.
- Do not connect LLM directly to Repository writes.
- Do not replace ModelGraph, Patch, Revision, Gate, Repository, or CAS main chain.
- Preserve offline deterministic RuleRuntime and existing public APIs where compatibility is practical.
- Reject invalid output before `append_patch`; preserve revision and graph hash on validator failure.
- Record actual prompt text hash, task spec hash, context hash, input/output hashes, provider/model, and repair metadata.
- Keep all new deterministic outputs stably sorted and preserve unrelated dirty worktree files.

## File Map

- `src/rflp_lite/methodology/contracts.py`: extend request/task/completion/failure contracts.
- `src/rflp_lite/methodology/registries.py`: resource-backed PromptRegistry and executable ValidatorRegistry.
- `src/rflp_lite/methodology/executor.py`: resolve actual prompt and build request; no generic fallback.
- `src/rflp_lite/methodology/validators/*.py`: context-aware executable validators.
- `src/rflp_lite/methodology/trace_rules.py`, `coverage_matrix.py`: predicate-aware traversal and stable matrix.
- `src/rflp_lite/methodology/repair_context.py`, `repair_planner.py`, `repair_strategies.py`: local repair pipeline.
- `src/rflp_lite/methodology/completion.py`: deterministic completion evaluation.
- `src/rflp_lite/methodology/context_planner.py`: P0–P4 selection and token budgeting.
- `src/rflp_lite/resources/prompts/**/*.md`: 23 task-specific prompt templates.
- `src/rflp_lite/resources/schemas/entities/*.json` or `methodology/entity_schemas.py`: focused payload schemas.
- `src/rflp_lite/methodology/workflow.py`: orchestration-only integration and audit persistence.
- `src/rflp_lite/methodology/gates.py`: Gate facade backed by trace/matrix.
- `src/rflp_lite/retrieval/planner.py`: gap-driven query helper/integration.
- `tests/methodology/**`, `tests/runtime/**`, `tests/retrieval/**`, `tests/e2e/**`: phase-specific contracts and fault fixtures.
- `tests/mbse_benchmark/**`: explicit three-track CLI and reports.
- `docs/DEVELOPMENT_STATUS.md`: v0.2 stage status and verification commands.
