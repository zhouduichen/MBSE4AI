# 结构选型驱动参数化 CAD 实施计划

> **执行约束：** 本计划只使用离线 preview 验证，不启动本机模型、远程模型、服务器、SSH 或 FreeCAD。

**Goal:** Make selected bracket/base structure options produce different allowlisted parameterized CAD operations and artifacts.

**Architecture:** `CadWorkflowService` is the deterministic compiler from a validated structure option to `CadOperation` objects. `PreviewCadAdapter` and `FreeCadRemoteAdapter` execute the shared `add_rib`/`add_fillet` contract; neither adapter accepts natural-language scripts. Existing approval, audit, PhysicalBlock, SysML, and deliverable paths remain unchanged and receive additive geometry evidence.

**Tech Stack:** Python 3.12, existing CAD ports, standard-library geometry payloads, FreeCAD remote script vocabulary, pytest, Ruff.

## Global Constraints

- Preserve the existing preview → approval → execution gate.
- Only `bracket-gusseted-plate`, `base-ribbed-plate`, `bracket-machined-block`, and `base-machined-block` compile to new geometry operations in this slice.
- Do not let LLM output become executable CAD code; all operation names and parameters are generated by deterministic application code.
- Keep unselected structure recommendations as recommendations; do not infer a default selection.
- Do not run local/remote models, SSH, server, or FreeCAD tests.
