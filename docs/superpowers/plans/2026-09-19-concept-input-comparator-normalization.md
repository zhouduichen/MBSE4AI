# 需求比较词规范化实施计划

## 目标

修复需求文本到概念设计指标包络的语义转换，使自然语言需求可以直接进入 2.1 候选布局链。

## 实施步骤

1. 在概念设计应用层定义中文最大值、最小值和确定值表达的规范化映射。
2. 先补充失败验收：九个确定值需求必须生成 `ready` 的 envelope，并产生 3–5 套候选；边界需求必须保留正确的 minimum/maximum 证据。
3. 运行聚焦测试，确认参数、边界、证据和来源 Requirement ID 均保持可追溯。
4. 运行离线全量门禁，更新开发状态和能力矩阵，提交并推送当前分支。

## 非目标

本次不引入新的 LLM Provider、不改变领域参数包、不启动本地或远程模型、不连接服务器或 FreeCAD，也不扩大到多轮稳定性实验。
