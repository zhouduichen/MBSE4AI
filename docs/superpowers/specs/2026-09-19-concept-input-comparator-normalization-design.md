# 需求到概念指标包络的比较语义规范化设计

## 背景

需求到总体布局的当前离线链已经能够从 ModelGraph 中抽取带单位的数字证据，但自然语言比较词仍直接作为内部操作符传递。这样“机翼面积为 24 m2”会被误判为最大值，“任务载荷不少于 150 kg”也不能稳定映射到最小边界，导致 `/concept-design/input` 无法生成可运行的指标包络。

## 目标

把需求文本中的常见中文比较表达统一为三个内部语义：

- `exact`：确定值，写入 `parameters`；
- `min`：下限，写入 `bounds.minimum`；
- `max`：上限，写入 `bounds.maximum`。

规范化后的操作符同时写入证据，保证输入建议、布局运行和审计结果使用同一事实。

## 决策

规范化放在 `concept_input_advisor._statement_values` 的抽取边界，不扩散到领域包、布局生成器或 UI。识别不到比较词时按 `exact` 处理；只有同时存在最小值和最大值时，才使用区间中点填充参数，单侧边界继续保持 `needs_input`，不猜测工程输入。

验收以自然语言需求直接生成指标包络并运行 3–5 套候选布局为主，同时覆盖“不超过/不少于”和“为/是/约为”三类表达。测试只使用规则 Runtime 和 preview 路径，不启动模型、服务器、SSH 或 FreeCAD。
