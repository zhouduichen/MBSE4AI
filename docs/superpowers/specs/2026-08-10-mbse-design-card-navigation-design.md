# MBSE 设计图模块卡片入口设计

## 目标

将 MBSE 设计图页面顶部的“总览、用例图、活动图、顺序图”从普通文本链接改为清晰、可点击的功能模块卡片，帮助用户快速区分不同设计图类型，并保持现有路由和后端逻辑不变。

## 设计方案

在 `mbse-diagrams.html` 中保留现有四个入口及其 URL，将 `.diagram-tabs` 改为四项卡片网格。每张卡片包含：

- 一个纯 CSS/文本图标区域，不引入图片或第三方依赖；
- 设计图名称；
- 一句说明：总览、参与者与系统目标、动作与控制流、生命线与消息方向；
- 右上角的小型类型标识；
- 当前页面对应的 active 状态。

卡片整块使用 `<a>`，保留键盘可访问性和现有导航行为。桌面端四列，较窄窗口自动降为两列，再降为一列。hover、focus-visible 和 active 状态沿用现有绿色强调色与深色面板体系。

## 边界与解耦

- 只修改设计图页面模板和 `app.css` 的卡片样式。
- 不修改顺序图领域契约、布局、SVG 渲染、路由参数或数据模型。
- 不新增图片、JavaScript、第三方组件库或全局状态。
- “顺序图”卡片继续指向现有 `/requirements/mbse/sequence` 入口；其场景选择和审核门禁保持不变。

## 验证

- 页面测试确认四个卡片标题、说明和原有链接均存在。
- 页面测试确认当前视图具有 active 标识。
- 全量测试和 `git diff --check` 通过。
